# DRAFT × DRAFT

> 運命のドラフトから、自分だけのチームを作れ。

**DRAFT × DRAFT** は、実際のNPB（日本プロ野球）ドラフト史実データをもとに、
ランダムに提示される「年度 × 球団」から実在の指名選手を1人ずつ選び、
12枠のロスターを完成させるスマホファーストのWebゲームです。

開発者による選手の能力評価・ランキング・強さ判定は一切行いません。
選手について保持・表示するのは、ドラフト順位や実際の守備経験、獲得タイトルといった
**客観的に確認可能な事実データのみ**です。ロスターの「強さ」をどう見るかは、
プレイヤー自身の野球知識と解釈に委ねられます。

## 遊び方

1. TOP画面でゲームモードを選び、**START** を押す
2. 「ドラフトする」たびに年度×球団がランダム抽選される（ルーレット演出つき）
3. その年・その球団が実際に指名した選手の中から1人を選ぶ
4. 空いている12枠のうち好きな枠を選んで登録（実際に経験したポジションは候補カードに参考情報として表示されるが、配置先を制限するものではない）
5. これを12枠すべて埋まるまで繰り返す
6. 完成したら打順を編集し、客観的なチーム構成・特徴タグ・実績バッジを確認してシェア

どの選手も空いている枠であればどこにでも配置できるため、配置可能な候補が0人になってゲームが詰むことはありません。

### ゲームモード

| モード | スキップ回数 | 備考 |
| --- | --- | --- |
| NORMAL | 3回まで | 標準ルール |
| NO SKIP | 0回 | 引いたら必ず指名 |
| HARD | 1回まで | それ以外はNORMALと同じ |

## このゲームでやらないこと

- 選手の能力値（コンタクト・パワー・球速など）
- 総合力・100点満点評価・S/A/Bランク
- 選手やチームの強さランキング、優劣判定
- 「最強」「弱点なし」等、主観に基づく評価表現

代わりに、ドラフト順位・出身（高校/大学/社会人/独立リーグ）・投打・実際の守備経験・
獲得タイトルといった事実だけを見せ、「この順位でこの選手はすごい」と
プレイヤー自身が感じられる体験を目指しています。

## 技術構成

ビルドツールに依存しない、素のHTML / CSS / JavaScript（ESモジュール）で実装しています。
`vite` などのバンドラは不要で、静的ファイルを配信できる環境ならどこでも動作します。

```
draftxdraft/
├── index.html            # エントリポイント
├── src/
│   ├── main.js            # 画面遷移・アプリ全体の状態管理
│   ├── dataStore.js        # data/*.json の読み込み（fetchベース）
│   ├── state.js            # ゲーム状態のファクトリ
│   ├── modes.js             # NORMAL / NO_SKIP / HARD とモード拡張フック
│   ├── draft.js             # 年度×球団の抽選プール・候補取得
│   ├── roster.js            # 12枠定義・実績ポジション表示用の判定（配置先は制限しない）
│   ├── game.js              # 抽選→指名→スキップ→終了判定のオーケストレーション
│   ├── battingOrder.js      # 打順の並び替え
│   ├── analysis.js          # 完成ロスターの客観分析・特徴タグ生成
│   ├── history.js           # ドラフト履歴の記録
│   ├── storage.js           # localStorage 永続化（壊れたデータにも耐性）
│   ├── share.js             # シェアカード用データ・Web Share API
│   ├── teams.js              # 球団名の年度別解決
│   └── ui/                  # 画面・コンポーネント・演出
├── styles/                 # CSS（デザイントークン / 画面別スタイル）
├── data/
│   ├── teams.json           # 12球団マスタ（年度別名称変更に対応）
│   ├── players.json         # 選手データ（能力値フィールドは持たない）
│   ├── drafts.json          # 年度×球団の実際の指名選手一覧
│   └── achievements.json    # タイトル/表彰バッジの表示マスタ
└── assets/
```

ゲームロジックと選手データは完全に分離されています。新しい年度・球団・選手を
追加したい場合は `data/*.json` にエントリを追加するだけで拡張できます
（年度・球団もコードに固定せず、データから動的に抽出しています）。

### データについて

選手データは調査に基づく客観的事実のみを収録しています。守備経験・二刀流判定・
タイトルなど確認が取れなかった項目は `null` または空配列のままにしており、
推測で埋めていません。そのため一部の選手は候補カード上で「実績ポジション不明」と
表示されますが、これは参考情報であり、ロスターへの配置先を制限するものではありません
（どの選手も空いている枠であればどこにでも配置できます）。

## ローカルでの実行

Node.js等のビルド環境は不要です。リポジトリ直下で任意の静的サーバーを起動するだけで動きます。

```bash
python3 -m http.server 8000
```

起動後、ブラウザで `http://localhost:8000` を開いてください
（`fetch` でJSONを読み込むため、`file://` で直接開くのではなくローカルサーバー経由で開く必要があります）。

## デプロイ

ビルド不要の静的サイトなので、GitHub Pages・Netlify・Vercel等にリポジトリの内容を
そのまま配置するだけで公開できます。

## ライセンス

選手データは公開されているドラフト結果・成績記録をもとに作成した客観的事実の集約です。
